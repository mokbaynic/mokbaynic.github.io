Suppose you are given the following small table named ' data ':

date sales
2025-05-20 2
2025-05-22 3
2025-05-23 1
2025-05-28 4
2025-05-29 3

Write a SQL query to retrieve all days with no sales between the starting date and the ending date.

Solution #1

We are going to use the sqldf library in R to solve the problem with recursion. A recursive query is one that calls itself repeatedly until a certain condition is met. 


# Load sqldf library
library(sqldf)

# Create data frame
dates = c("2025-05-20", "2025-05-22", "2025-05-23", "2025-05-28", "2025-05-29")
sales = c(2, 3, 1, 4, 3)
data  = data.frame(date  = dates, sales = sales)

# Write SQL query
query = "
          WITH Constants AS (
                      SELECT MIN(date) AS min_date,
                             MAX(date) AS max_date
                      FROM   data
          ),
          
          REC AS (
                      SELECT min_date AS date FROM Constants
                      UNION ALL
                      SELECT DATE(date, '+1 day') AS date FROM REC
                      WHERE  DATE(date, '+1 day') < (SELECT max_date FROM Constants)
          )
          
          SELECT date
          FROM REC
          WHERE date NOT IN (SELECT DISTINCT date FROM data) 
          AND date > (SELECT min_date FROM Constants)
        "
# Run query and display outcome
sqldf(query)

The records are arranged in chronological order. Using recursion enables us to loop through all theoretical dates between the earliest date and the latest date. For efficient computation, it is best to store the maximum date as a constant in a common table expression (CTE). This way, it doesn't have to be recomputed every time the program checks whether the next date to be considered in the recursion comes before the maximum date.

Let's take a close look at the REC common table expression in the query. First, we create an initial record with the minimum date as its value. Secondly, we create the next record by computing the next calendar day as long as it comes before the maximum date. This step is recursively applied to REC until the next calendar day is no longer anterior to the maximum date.

At last, we simply extract from REC all dates that did not occur in data and obtain

date
2025-05-21
2025-05-24
2025-05-25
2025-05-26
2025-05-27
